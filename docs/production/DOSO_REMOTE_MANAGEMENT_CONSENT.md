# 远程管理与数据边界

文档核对：2026-11-08。远程状态App、业务API、数据库许可与状态投影已有实现；业务接口与云Gateway自动同步已有部署记录。2026-11-07已完成已登记模拟设备、实际Web App和真实业务数据库的状态流程，设备源为模拟Brainstem，传输包含SSH隧道。[验证范围](D:/DOSO/robot-cloud/docs/SIMULATED_FLOW.md)。真实机器狗、G20和5G仍待验收。

## 用户选择

- 每台机器狗的远程管理由其授权用户主动开启；未选择、无法核实或授权失效时按关闭处理，不因绑定设备、登录或连接网络自动开启。
- 开启前说明上传范围、用途，以及可以随时关闭；入口和状态需要区分“已关闭、等待设备确认、已开启、关闭待确认、不可用”，不能把保存了开关显示成设备已执行。
- 本批远程状态使用真实 Brainstem `Status`，包含运行状态、姿态切换、控制来源、电机输出及关键故障标志，并显示设备可达性和原始采集时间。电量、充电状态、定位和软件版本在取得真实数据源并扩展合同后接入。任务及其执行回执仅在启用对应功能时传输。
- 远程视频、图片、录像、地图、详细日志、语音和环境图片不因开启远程管理而自动采集或上传；各功能另行说明并由用户主动选择。远程观看、云中转和云录像分别表述。
- 本地电机控制、平衡、避障、急停及本地任务由本地系统及安全链路负责，不能依赖云端在线状态或以云端开关绕过本地保护。

## 关闭与断网

本节是完整产品要求。现有代码已能关闭采集与云端入站，也能在机器狗本地选择文件关闭后退出连接；可信本地开启/重新开启，以及远程明确关闭后保存关闭状态并断云，仍待接通。当前进度见 [robot-cloud推进记录](D:/DOSO/robot-cloud/PROGRESS.md)。

- 关闭请求到达服务端后，立即拒绝该设备新的远程状态入站和新远程任务；已在途的数据及处理结果必须按服务端生效时间核对。禁止用隐藏页面或本地 UI 偏好代替服务端门控。
- 设备端必须独立执行上传门控：撤销生效后停止采集、排队和发送用于远程管理的状态，并清理尚未发送的此类队列；本地安全和本地操作所需数据不受影响。不得在之后重新开启时补发关闭期间的数据。
- 对于此前已签发采集许可的设备，如果其离线或未确认本次关闭，界面显示“关闭待设备确认”，不得声称设备已停止发送。未曾开启的设备保持默认关闭。设备重连时先核实最新授权再恢复上报；无法核实的情况默认不上报。已发送至网络的数据无法撤回。
- 远程命令在服务端及设备端分别校验授权、时效和本地安全；关闭或失联时，不执行排队的过期命令。通信确认不等于任务已执行，需使用独立的设备回执。
- 历史数据不会仅因关闭自动删除；具体保留期限和删除操作应由产品另行提供清晰说明，不在本约定中虚构已实现的删除功能。

## 当前实现的职责

- App 设备页读取每台真实设备的云端选择，用户主动点击开启或关闭时提交变更。初次打开只读取，设置未知时禁用操作。前台自动读取最新状态，后台或离开页面停止页面请求，用户的云端选择由服务端保留。
- PostgreSQL 是用户选择、许可版本、采集会话和最新状态投影的唯一归属。后台同步独立于 App 运行，按设备当前归属与授权代次签发、续期或撤销短时许可。设备换主或授权代次变化后默认关闭并清除旧状态投影。
- Gateway 验证设备连接和签名消息，按业务数据库返回的许可执行。许可、会话复用、确认和到期规则以 [Rust 正式合同](D:/DOSO/robot-cloud/CONTRACT.md) 及 [共享 reporting 类型](D:/DOSO/robot-cloud/shared/src/reporting.rs) 为准。
- 关闭事务提交后拒收旧授权报告。界面分别展示用户选择、设备确认和数据新鲜度。读取失败保留错误事实，上次成功状态保留原始时间，重复缓存不会刷新时间。远程命令的独立执行与安全门控仍须按对应功能验收。

业务接口与后台同步约定见 [用户远程状态接口](DOSO_REMOTE_STATE_API.md)。地图目录和文件授权另见 [地图接口合同](DOSO_MAP_LIBRARY_API.md)，两者授权分别处理。
