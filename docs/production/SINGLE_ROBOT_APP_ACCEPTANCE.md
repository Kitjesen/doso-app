2. 点“生成连接申请”。预期显示“本机身份：等待授权”和“连接申请已生成，等待授权。”。保持页面前台及已授权USB连接，由受控电脑工装导出当前公开CSR并核对目标、requestId、SPKI；G20私钥留AndroidKeyStore。生成申请仅证明本机身份准备，不是连接成功。
3. 工装用该机器狗的受控CA签发公开授权包，传回当前申请；再在App点“读取授权结果”。只有本机公钥、请求、目标、证书链、用途和有效期等核验通过，才应显示“本机身份：可用”和“本机身份已就绪。”。当前不是自动一键配对；不能让用户反复点击等待来代替签发。短期工装窗口因后台/超时失效时应显式重开并核对当前申请，不能套用旧批准。
4. 点“检查连接状态”，查看“连接诊断”。“身份握手：已验证”要求状态、策略、电压、电机四次真实RPC均报告mTLS且叶证书指纹一致；本机ready时还须匹配该身份的叶证书。另核对真实机器人状态、当前策略、总线电压、电机在线数及故障，不能只看文字“状态已读取”。可选诊断失败会保留基本状态，因此有部分数据不等于四项通过。
5. 当前诊断快照15秒后过期；重新检查得到新结果，断开网络应报错/失效，恢复后重新检查。重开App时已安装身份须能恢复且无需再次签发；这两项需要实机另外留证，不能以代码测试代替。
