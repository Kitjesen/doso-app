# DOSO 核心产品闭环推进清单

核对日期：2026-10-12（Asia/Shanghai）。依据当前源码和用户新要求；状态描述不是承诺永久砍掉能力。

## 产品目标与纠偏

路线不是“永远只能看模板”的功能。目标流程为：选择设备 → 同步设备地图 → 新建/编辑航点 → 保存路线 → 设备侧校验/同步 → 执行 → 进度/停止与结果。

Figma 图片只作为设计参考，不能替代设备地图、坐标或障碍物。当前缺少地图数据合同和接入，不通过删除说明或开放按钮伪装已完成。

个人资料明确区分：昵称（显示名称）和用户名（唯一账号标识）。用户已要求两者可修改；旧的一次性用户名认领规则不能充当产品需求。修改用户名通过新受保护接口实现，原注册/首次认领行为保留。

## 本批次 A：入口与个人资料（立即实施）

| 内容 | 当前缺口 | 实施与验收 |
| --- | --- | --- |
| 控制中心入口 | 只有首页设备卡内“控制预览”，难发现 | 首页明确“控制中心”；“我的设备”增加同一入口；返回原页；进入不发送指令 |

| 头像 | 固定素材，无上传服务 | 系统相册选择、预览/取消/移除；私有存储、每用户隔离、类型/大小限制；只在保存成功后更新共享头像 |
| 部署与原生包 | 新 RPC/存储与原生相册模块未部署/打包 | 本地代码/测试与迁移先交付；托管部署和真实保存另验收；旧开发壳不能冒充包含新原生模块 |

## B：地图与路线管理（不是模板展示）

1. 已定位 Brainstem 仓库 `D:/inovxio/brain/brainstem`；接下来确认地图标识和版本、坐标系/单位/边界、底图格式、定位与同步、路线校验和执行状态。已读状态接口不等于地图/导航接口齐备。
2. 建立地图与路线数据层：按用户/设备隔离；路线绑定地图版本；保存草稿与可执行路线分离；编辑冲突和旧图失效可恢复。
3. 实现实际编辑：新增/移动/删除航点，撤销，重命名、保存/重新打开、删除确认；无地图时显示明确空态与连接/同步入口，不画假路线。
4. 本地输入校验不等于设备可执行验证；必须有设备地图/路线版本、可信校验结果和执行权限。
5. 用真实地图完成保存后重开、换账号隔离、断网/保存超时、地图更新失效的测试，再验收执行。

当前事实：MapScreen 三条硬编码模板均无 routeId；仓库没有地图/路线/航点存储表和服务。不能用一张 Figma PNG 推导真实机器人坐标。该外部合同缺失不阻碍 A 批实施。

## C：在线账号与机器人闭环

1. 核验后端 DNS/TLS、Auth 与迁移部署，专用测试账号完成注册/收码/登录/重启恢复/退出/找回。
2. 真实设备身份/绑定 → 可信心跳和遥测 → 断线/过期状态；先只读。
3. 真实非运动健康检查及 ACK；随后才实现运动控制，验证断联保护、急停/硬件互锁和失效安全。
4. Android 当前源码原生包与证据；iOS 扫描适配已补源码，另补签名/真机条件和权限/扫描测试。

当前生产 executor 为 null；模拟测试不能替代 Brainstem 实机证据。安全锁不因界面改名或资料修改而开放。

## 本批验收边界

- 新 UI：默认、编辑、取消、校验失败、重复提交、保存成功/失败、大字/横屏及回退。
- 服务：只更新当前用户允许的字段；用户名冲突事务回滚；照片签名/类型/大小与用户归属校验；网络失败不冒充保存。
- 数据库：旧 claim_username 仍守原约定，新编辑 RPC 与头像策略独立受保护。未运行真实数据库测试或托管部署不得标通过。
- 现有认证、路线启动、安全和共享样式相关回归；typecheck 与 Expo 导出。
- 截图必须区分 Web 开发预览、Android 原生证据、设计提案。不得以本批修改增加未完成的 20 页正式通过数。
