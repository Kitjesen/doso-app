# 地图与路线页

对应已确认设计稿 exec-2879da21-2871-4273-abd2-b4e665324645.png。

- MapScreen：大地图、单层筛选、白色路线卡片、查看和名称编辑面板。
- RoutePreviewMap：独立可点选的途经点、代码绘制路径、全屏及回到全览。
- routePreview：仅界面演示数据，未提供可信路线 ID，不进入执行链路。
- 复用 ControlPanelMotion 的180ms淡入与轻移，并尊重减少动态设置。
- 导航选中态统一为浅冰蓝。

正式页面 showExamples 默认 false，缺少路线时显示空状态；连接设备仍使用原有 onOpenNavigation。演示模式的收藏、名称编辑和新建都是会话内状态，不保存到云端、不发送运动命令。新建演示路线复用模板几何，不宣称新增地图规划算法。

assets/scene/route-campus.png 由内置图像生成工具依据批准设计生成，提示为仅生成无路线和无UI的冰蓝/淡紫虚构园区地图；真实路径覆盖由组件绘制。

验证：筛选/收藏/选中一致性、详情/名称验证、演示隐藏、命令隔离、320和390竖屏、844横屏、减少动态偏好。原生键盘与真机触控仍待设备验收。

## 新用户无地图状态

浅色背景从高饱和冰蓝收敛为 #F5F6F8，操作色 #303C4D，选中底 #E7EBF1。移除界面的演示字样，但数据隔离逻辑继续保留。没有地图时展示添加第一张点云地图入口与0条路线，不显示地图图像、里程、筛选、新建或编辑。正式连接入口沿用 onOpenNavigation；QA空状态连接至设备绑定页。
