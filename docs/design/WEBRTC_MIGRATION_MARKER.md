# WebRTC 迁移目标标记

记录日期：2026-10-23。状态：**用户确认的后续方向，待正式设计与实现；未接通、未部署、未验收**。

森哥明确要求：“后续也要迁移到WebRTC承载图传、点云、状态和控制，作为标记。”本记录保存方向与迁移边界，不表示本轮替换协议，也不是开通服务、部署或真实运动授权。

## 已确定与尚未确定

已确定目标：后续由WebRTC承载图传、点云、状态和控制；界面不再依赖传输类型直接持有运动能力。控制页与主界面品牌、字体、导航语义保持连续。

尚未确定：SDK/版本、机器人侧适配落点、媒体编码、data channel数量/可靠性/有序性/重传、消息合同、信令/ICE/STUN/TURN、跨网拓扑、性能阈值与时间表。不能把“目标确认”升级成这些具体实现已批准。

当前继续保留已有gRPC接入：src/services/brainstemGrpc.ts与modules/brainstem-grpc只实现GetControlStatus的单次原生TLS读取，身份选择、前台限制与取消不变；motionAuthorized/cloudBindingVerified仍false，App.tsx生产executor=null。这不等于真实图传、点云、地图、动作或设备绑定已接通。

## 载荷与接口边界：正式设计的起点，不是冻结合同

| 载荷 | 候选承载 | 正式合同与验证项 |
|---|---|---|
| 图传 | 媒体track | 真实相机来源、编码/硬解、时间戳、分辨率/帧率/码率、冻结/陈旧识别与延迟 |
| 点云 | data channel | 坐标系/单位/时间/帧号、压缩/分片/完整性、大小上限、丢弃和背压；不默认把点云编码成视频 |
| 状态 | data channel | 设备与会话身份、采样时间/序号、新鲜度、快照/增量、缺失与断连语义 |
| 控制 | 独立逻辑控制data channel | 身份、控制租约、会话代次、严格命令序号、有效期、首包零速确认、ACK、停止与释放 |

独立data channel不自动保证网络/CPU资源隔离。点云不能阻塞控制队列；具体优先级、可靠性和降级策略需测量，不能先声称WebRTC就能解决延迟和掉线。

正式实施前必须明确的模块所有权：

- 机器人端适配负责会话身份、授权、现有Brainstem控制仲裁与失效安全；不能只转发未验证消息。
- App传输层拥有PeerConnection、媒体/data channel、连接代次、取消和释放；向上投影状态，不直接调用未经保护的运动接口。
- 输入/控制协调层拥有触屏与实体输入互斥、限幅/时效、租约/序号/ACK和唯一命令出口，传输替换不得绕过它。
- UI负责画面新鲜度、状态/权限和结果呈现；云账号/设备归属继续独立验证，不能被连上局域网或收到视频替代。

这些是未来责任边界，具体代码模块/公共接口尚未落地。会话密钥、控制令牌和待发运动意图不得作为可重连重放数据持久化；缓存应限容量与时效，日志不记录凭据、令牌或完整敏感信令。

## 迁移不得丢失的安全语义

1. WebRTC加密不自动授予运动权限。账号、设备归属、机器人身份和租约分别校验；信令与实际机器人会话身份的绑定方案待设计。
2. 保留Brainstem实际合同中的身份/租约、FSM/电机/故障门禁、有效值与限幅、首个非零输入前的零速确认、命令序号和ACK匹配。新会话不能继承旧控制权或迟到回包。
3. 区分收到、接受、执行中和结果确认；发包成功/Empty回复不等于姿态、电机或物理停车已完成。超时显示无法确认，不乐观成功或自动重试动作。
4. 输入过期、后台、离页、输入源切换、旋转/失焦、被抢占或断连时撤销运动意图；独立心跳不得继续续租维持陈旧非零输入。
5. 停止优先于普通动作互斥、面板/确认和媒体负载，但仍受有效身份和服务端校验。健康通道可尽力发零/释放；断网不能保证最后一包送达，机器人侧租约/看门狗兜底需保留并实测。普通停止、释放、电机失能和硬件急停分别定义。
6. 关键后台安全职责不能仅依赖后台JS定时器；前台恢复或迟到ACK不能自动恢复运动。原gRPC读取的正常信任/主机名校验/后台取消不得因迁移降级。
7. **同一控制会话只能有一个明确的运动命令出口。禁止gRPC与WebRTC双发，禁止自动回退到gRPC并重放，禁止重连重放旧命令。** 只读对照须标设备、来源和时间，不能产生第二运动权。人工换通道须先失效旧会话，再按新会话鉴权/租约/零速握手。

当前本地默认300ms租约只是源码配置背景，不证明现场配置、实际停止时间或物理瞬停。现有云卓SBUS仲裁与App gRPC/WebRTC输入来源不能混同或冒用优先级。

## 验证、发布与回退标记

| 阶段 | 证据门槛 |
|---|---|
| M0 正式设计 | 实际部署与协议核对；模块/接口/存储生命周期、身份绑定、四载荷合同、单命令出口、失败与回退规则、预算评审 |
| M1 隔离验证 | 无硬件仿真中验证乱序/重复/丢包/拥塞/重连/旧ACK、权限拒绝和不重放 |
| M2 G20只读 | 匹配源码新原生包；真实视频/点云/状态来源、资源与生命周期测量；实体轴另在机器人断开时观察 |
| M3 仿真控制 | 租约/序号/首包零速/ACK、停止优先、媒体满载、后台/失联/抢占及机器人侧兜底 |
| M4 受控实机 | 另行取得明确动作授权、现场保护与限幅条件；逐项验证，不能由设计稿或M1/M2替代 |

G20的SDK/ABI、硬件解码、CPU/GPU/内存/温度/电耗、拥塞下图传延迟/点云队列/状态新鲜度/控制ACK与停止兜底尚未验证，不预先承诺帧率和延迟。实体摇杆MotionEvent/HID/厂商接口及轴向/死区/回中/断连仍未知。

回退表示关闭未验证迁移能力、保留证据并回到已验证范围，不是在运动中自动换通道。出现权限不明、双发/重放、停止或兜底不达标、资源预算失败时停止进入下一阶段。灰度、混合版本和回退开关需在发布候选前定义。

## 未决项的重审触发

- M0前确定SDK/原生边界、机器人适配、身份/信令和关键ADR；任何新原生依赖/ABI或部署改变时重审。
- 首次真实数据前确定媒体与点云编码、时间/坐标合同；来源/格式变化时重审。
- M1前确定通道顺序/可靠性/重传/队列；M2/M3时效或阻塞不达标时重审。
- 首次跨主机前确定ICE/STUN/TURN/直连中继与安全；跨网/NAT变化重审，不擅自开通付费服务。
- 任何控制实现前核实Brainstem实际仲裁/租约/停止合同；协议或现场配置变化时重审。
- 发布前确定G20预算、输入仲裁、灰度与回退；系统/硬件变化重审。
