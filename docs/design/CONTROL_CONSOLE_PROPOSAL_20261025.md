# DOSO 轻量操控台设计提案

状态：设计稿，未迁移到App运行代码。用户最新反馈否定上一版观感；局部测试通过不代表审美通过。本次先形成一个可比较的方向，保留品牌、导航和已有控制合同。

## 主要判断

当前页面的弱点是视觉权重与控件表达不一致。大DOSO虽然淡，面积仍压过仅有细线的摇杆；圆盘叠加外框、行程圈、十字线、内环和中心小点，像校准图而非可拖动控件。顶部几组文字缺少主次，底部圆形动作则孤立且淡。继续逐个放大或换色，无法形成完整的控件语言。

两条独立设计复核在上述原因上基本一致。对底托是否需要新增灰色胶囊有不同建议；本提案选择不增加整块灰底，用一致的形状、基线与20dp间距分组，遵循用户此前减少底色与外框的要求。

## 推荐的一套方向

白色画布直接铺满控制页，保留THUNDER-01居中24sp。右侧仍为无框图标和文字，48dp命中区保持。遥测使用14sp次级标签、24sp主要数值，避免标签、数值、设备名同时抢视觉权重。这里是对“全部放大”的主动修正，未用更小数值换取留白。

两个轮盘保持约194dp与既有位置，外盘使用当前surface实底且不描边。拇指保持原66dp和投影行程，采用raised白色和单层轻功能阴影；22dp移动/水平转向符号取自既有Ionicons。移除circle分支的行程环、十字线、拇指内圈和4dp小点；cross分支与实际输入处理不变。圆面形状在离线时仍可见，方向符号使用中性色，实际禁用状态不改变。

大DOSO保留196sp响应式上限，仅将浅色透明度从0.05降至0.025，退到控件后面。它是装饰，不拦截触控，也不进入辅助功能树。底部继续停止、站立、坐下、一个电机开关，64dp圆形区域和14sp短标签；停止沿危险色，电机亮暗仍按已观察状态区分，与输入是否就绪分别处理。

不增加新颜色体系、灰色大卡、虚构地图/图传/遥测、装饰动画或新的业务入口。沿用MiSans和当前语义颜色。Apple关于熟悉图标、清晰短标签和按钮角色的指导可作为表达参考，但本方案是DOSO的设计取舍，不宣称符合全部Apple规范：https://developer.apple.com/design/human-interface-guidelines/buttons 。

## 设计稿与实现边界

设计稿由artifact打包阶段对两个组件做精确允许列表变换，未写回src。manifest同时记录原始与变换SHA。真实配对/单杆响应器、死区、行程数学、回零、20ms持续采样及动作权限/确认不在变换范围；八项源码守卫只证明提案没有改动所检代码，不证明真实通信或物理停止。

主图保持离线、未知遥测和禁用动作。没有通过假在线使设计稿显得更完整。浏览器零边距SafeArea和Web阴影不能证明G20原生材质、手感或系统栏适配。若迁移，仍需确认按下/拖动/松手、就绪/离线/失联、实际电机已使能但输入未就绪、错误/确认、大字体与深色等状态，尤其不能用新的材质改变状态语义。
