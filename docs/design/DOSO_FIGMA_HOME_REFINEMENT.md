## 可以改的部分

1. 配色：按用户此前要求将绿色强调改为克制蓝色，保留白底与轻量卡面。使用语义错误色处理错误，离线与不可执行保持中性，不能把禁用召回变成亮蓝可执行状态。
2. 字号：源码返回快捷标题 11.52、说明 7.2，遥测说明 9，确有可读性问题。建议快捷标题 14/20、简短说明 12/18、状态 13/18、主要操作 16/22；以实际原生渲染决定必要的卡片增高与留白，不把整套画面粗暴放大。
3. 文案：缩短说明为「预览路线」「预览任务」「查看状态」等符合能力边界的文案；不继续使用与真实能力矛盾的「启动自主巡航」「执行指定任务」。
4. UX：整卡命中区域至少 48dp，卡片和箭头触发同一动作；选中与按压仅改变局部底色/描边，不跳动布局；导航保留 selected 语义。横屏沿用原稿左右重排结构，不能缩放竖屏或压缩成小字。
