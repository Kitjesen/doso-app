## 2026-10-18 新参考迁移：主视觉卡 + 信息层级 + 原生图标家族（v5/v6）

森哥补充了两组可参考的界面：一组使用大主卡、堆叠信息卡和柔和插画，另一组使用白色画布、主视觉卡、指标入口、任务列表和简单底部导航。本轮只迁移它们的**设计语法**，不复制外部品牌、插画、照片、文案或演示数据。

- **结构可借鉴**：首页设备身份／连接状态作为主卡，下面接少量真实快捷入口；任务页以当前模板、说明、只读步骤和状态形成主次层级；分析页可采用“主视觉卡 → 指标行 → 趋势区”的阅读顺序。卡片大小按内容职责分层，不把每个字段再包一层卡。
- **表面规则**：继续使用白色／石墨画布 + 单一中性 `surface` + `#98D1FF` 操作强调。柔和的其他色只允许作为小面积语义图标或选择反馈，不能恢复整页多彩底色或装饰性渐变。边界线只保留表单焦点、错误和必要分隔，不作为普通卡片轮廓。
- **字体与图标**：保留 DOSO MiSans、现有字阶和五项品牌导航；主标题、卡题、说明和指标值按既有 `typography.ts` 层级排列。功能图标使用同一套原生矢量图标家族，避免白底 PNG 托底；品牌 Logo 候选仍需独立母版与透明度审查，不能把参考图 Logo 当 DOSO 资产。
- **无描边细节**：日期／筛选等选择器只用选中圆、字色和间距表达状态；Analysis 预览样式中的日期网格与未选日期胶囊不再绘制 hairline 外框，避免与“去掉线框”的要求冲突。
- **真实能力边界**：参考中的山景、花朵、钢琴、虚构日期／任务进度和“已完成”状态不进入业务数据。设备电量、连接、安全锁、任务执行和分析历史仍只显示真实来源；未知时保留“待同步／不可用”，不以预览图或静态指标冒充遥测。

本轮已将 `AnalysisScreen` 的预览样式收敛为同一中性卡面，移除残留绿色装饰底和多余内层填充，同时保留预览明确标识；生产空态继续显示可信数据未同步。相关局部检查为 `scripts/analysis-appearance.test.mjs`，不等同 Android／iOS 或正式 20 页视觉验收。后续其余页面沿同一结构规则继续收敛，优先检查真实状态、窄屏和深色模式。

路线页的可见强调也已对齐同一 appearance：路线说明箭头、空态地图图标和当前路线库指示使用 `blueInk`，不再从 legacy `greenDark`／旧 authPrimary 取色；路线可执行门和示例数据合同保持不变。
