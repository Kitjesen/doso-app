# DOSO 逐页打磨清单

更新：2026-10-23。森哥已明确要求把完整界面设计落实到 App 运行代码。全部入口纳入逐页设计、实施和验证范围；批1首页/任务及批2地图/分析/我的已完成本轮自适应代码和本地回归，不把五个主页面改动算成全 App 或原生视觉验收完成。

保留原白／石墨／柔蓝配色、MiSans、DOSO 品牌及导航契约，不再用整体换色代替布局优化。UI 实施不授权新增生产权限、云端部署或真实机器人运动，也不代表尚未接通的设备能力已经可用。

## 数量口径

- **完整入口26个 = 24用户界面 + 2开发工具**。既有“25入口”是App路由口径，另需计入index.ts独立开发本地仿真入口。
- `src/types.ts` 的 AppStage 为19项；main是壳，18个非main入口 + 五个主Tab + DataPrivacy全屏Modal + 开发连接诊断 =25。
- `index.ts`另有受`__DEV__`和显式仿真开关保护的`BrainstemSimulationScreen`入口，不属于生产导航，不因此新增生产能力。
- `docs/design/DESIGN_ACCEPTANCE_MANIFEST.json` 为**20项正式验收**，不是整个App只有20页；本清单不改变正式0/20。
- 注册/恢复验证码共用 EmailOtpScreen；配网/固件当前共用 DeviceUnavailableScreen。复用布局一起打磨，不重复设计，也不把两个用途合并为同一业务。
- 浅色/深色/横屏、键盘、加载、空态、错误、权限拒绝与确认弹窗均是同页变体，不另计页面。设备资料错误是独立stage但复用通用错误壳；Loading/ServiceError全局壳另做状态清单。

### 共享壳的兼容边界

批2已将App与DesignQaRoot的五个主页面Header统一为正常流，并同批移除Map固定顶部补偿、Profile设备/控件偏移及左安全区回收。五页均用onLayout实测可用宽高；不能因窗口总高足够就假定扣完页头后仍可双栏。壳层统一保留四边安全区与一次导航预留，页面不再重复扣除或回收。相关组件/helper/handler与契约通过仅是本地证据，系统栏、真实窗口、文字渲染及触控仍需原生验证。

### 每批共用验证矩阵

| 维度 | 检查范围 |
|---|---|
| 手机竖屏 | 320与390逻辑宽；内容、导航及主要操作不横向溢出 |
| 短横屏 | 844×390窗口；高度不足时不强行维持拥挤双栏，重要操作可滚动到达 |
| 宽横屏 | 拟议960×600、1280×800测试窗口；按实际可用容器决定分栏，而非仅看横屏方向 |
| 字体缩放 | fontScale 1／1.3／1.5；核对标题、状态、输入、按钮及日期可读性，大字允许回退单列 |
| 外观与内容 | 亮／暗模式、长文本、长用户名、空态、加载、错误和不可用原因；不靠颜色单独表达状态 |
| 系统与输入 | 左右安全区、状态／导航栏、键盘弹出、滚动可达、返回和焦点；区分设计几何与真实触控范围 |
| 功能契约 | 原导航顺序和动作回调保持；认证／资料保存状态不丢失；只读、禁用和任务安全校验不放宽 |

宽横屏尺寸是测试窗口，不是已经测得的 G20 dp／DPI。G20 最终验收须以实际窗口、显示密度、字体缩放和系统栏为准，再验证目标 APK 的安装、启动、原生字体与触控。实体摇杆、RF传输和机器人运动能力另列，不能从横屏显示通过推导出来。

2026-10-23接入补充：G20用户指认的设备已授权ADB，Android13/API33/arm64，physical1200×1920、既有density override408，推算横屏约753×471dp；实际RN窗口/安全区/有效fontScale未测。现按675×359等合成内容尺寸补本地回归，不降低800/480共享分栏门槛或缩字号。旧QA f313包基础安装/启动/旧注册页与IME收起有实机证据，但不能冒充当前源码的新UI通过；须先取得匹配当前依赖的新测试包。

## 逐页收敛规则

每页依次确认：**字体/字重 → 信息主次与文案 → 卡片/留白/大小 → 颜色角色 → 状态及交互**。一页确定后冻结该页方向；后续共享组件改动应明确影响页，不能反复重画已定页。设计图通过不等于实现或原生验收。

颜色沿用现有白／石墨／柔蓝，不新加背景层；细微调整按具体卡片讨论。App继续使用MiSans，候选新字库不自动全局替换。字体样张在 `artifacts/ui-refresh/20261019-layout-index-type-v12/index.html`；真实字体手机稿在 `artifacts/ui-refresh/20261020-realtype-mobile-v13/`，G20横屏稿在 `artifacts/ui-refresh/20261022-g20-landscape-v14/`。

配网和固件没有真实生产能力时继续显示不可用，不画模拟进度；分析没有可信遥测时保留诚实空态，不用演示图表填充生产页面。页面数量、代码改动数和设计稿数量都不能直接增加正式通过数；正式20项按原验收证据逐项判定。
