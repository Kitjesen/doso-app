# 首页定稿实现

源参考：exec-d83ffcf8-98c4-4a5b-bf05-c7cd5a384402.png（用户已选定的 D+E 合并稿）。

HomeScreen：设备与场景；HomeSummary：今日足迹、最近动态及详情弹层；BottomNav：地图、任务、首页、分析、我的，首页居中更大，视觉隐藏标签但保留无障碍名称。

assets/scene/home-spring.png 是图像生成工具依据定稿制作的装饰背景，不是实际设备环境。src/design-qa/assets/home-map.png 是仅用于隔离预览的示例地图。生成提示：从定稿重建无 UI、无文字、无机器狗的樱花远山背景；另生成无 UI 的虚构公园轨迹图。

正式首页继续使用既有设备电量、连接状态及 last_seen_at；新地图摘要和最近动态只提供展示接口，尚未接入云端历史查询，没有数据时显示空态。QA 专属 HomeFixture 提供设计数值与图片，不由正式 HomeScreen 引入。地图展开是详情视图；QA 图片不是可导航地图。

REA 修改前证据：ev_50b07c568d5dace8e0ea90c87411092b64adee8e9f3f82b822f0cc70a62b97a0。采用源码实现，不声称从图片反编译出原始程序。

验证：字体/导航/真实空态/零值/无示例数据依赖，以及展开和关闭详情。浏览器 390×844、320×700、844×390；iOS/Android 真机未验收。
