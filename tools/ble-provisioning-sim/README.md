# BLE Wi-Fi 配网离线通信切片

本工具模拟 App 客户端、机器人配网服务、BLE 字节分片和网络适配器之间的通信。它没有连接蓝牙、读取真实网络、调用系统 Wi-Fi、修改账号或发送机器人动作，也没有接入正式 App 页面。所有 SSID、口令、制造身份和配置授权均为本进程内生成/定义的测试数据；不接受真实 SSID 或密码参数。

在仓库根目录使用现有 Node 24 运行：

```powershell
node tools/ble-provisioning-sim/run.mjs all
node --test tools/ble-provisioning-sim/protocol.test.mjs
```

可选场景只有 `success`、`wrong-password`、`timeout`、`cancel`。结果仅输出固定事件与状态，不输出 SSID、密码、私钥、会话密钥或密文。导入现有 `.ts` 领域状态机时，Node 可能提示 `MODULE_TYPELESS_PACKAGE_JSON`；无需为这个工具修改项目 package 类型。

## 真实产品流程与当前模拟结果

1. App 发现设备后，核对已信任的制造公钥并验证机器人会话签名。
2. 机器人核对配置授权：设备、终端、认证会话、授权代次、恢复出厂计数、有效期及当前客户端临时公钥均绑定。广播设备名、同网、连接成功或 CSR 持钥本身均不授权配网。
3. 两端建立加密会话，经有界分片下发 Wi-Fi 配置。机器人仅受理一次凭据写入。
4. 网络适配器先尝试临时连接，机器人发送经签名和加密的联网/失败报告。
5. App 在模拟 IP 链路发起新挑战，复核同一制造身份、请求、地址、随机挑战与有效期，再明确确认保存网络配置。

`success` 仅表示模拟网络已确认且 IP 侧同设备身份已复核，结果为 `verified-network-awaiting-bind`。复用的真实 `src/domain/device-provisioning/index.ts` 此时保持 `awaiting_confirmation`；`cloudBindingCommitted` 始终为 false。没有伪造云端所有权确认以凑出 `succeeded`，也不绕过当前用户认领的前提。

真实 IP 复核要求 G20 与机器狗在可互通的网络中，常见是同一局域网，但仍可能被 AP 隔离、网段或路由阻断。配网改变机器人网络，不会自动使 G20 加入该网络；G20 切换 Wi-Fi 需要 Android 系统界面、权限和用户许可，不能承诺静默切换。机器人已连 Wi-Fi 但 IP 复核失败时，应显示网络可达性或身份复核问题，不能重新标成 Wi-Fi 密码错误。此工具直接调用虚拟 IP 端，不证明 Android 切网、真实地址发现或路由已接通。

提交前的错误口令、超时、取消及取消后迟到的网络结果均保留原有模拟网络；未通过 IP 身份复核前不提交新配置。模拟网络适配器的连接/提交/回滚均绑定独立 attempt，旧回调只能清理自己的 checkpoint，不能设置或清除新会话候选。真实机器上须由系统网络服务的 checkpoint/回滚能力实现并实测，不能把此处的内存赋值当作操作系统保证。

提交请求发出后，客户端以 `commit_pending` 拒绝取消，不能把未知提交结果说成已回滚。收到提交确认后两端关闭当前配网切片；后续取消/过期明确返回 `already_committed`，不更改已提交网络或把领域状态改成 cancelled。新的配置必须使用新的授权会话。预期网络错误只接受适配器显式的 NetworkError；内部 TypeError 等异常清理本 attempt 后原样上抛，不伪装成密码错误或设备拒绝。

本切片没有丢失提交确认的自动恢复，不会盲目重发或显示已取消；真实适配需要先查询/确认提交结果，再恢复流程。

## 文件边界

| 文件 | 作用 |
| --- | --- |
| `protocol.mjs` | 有界 UTF-8 消息、ATT 分片、签名、会话加密及 Wi-Fi 字段验证 |
| `flow.mjs` | App 与机器人两端，复用既有领域 reducer；不包含系统网络命令 |
| `fixture.mjs` | 仅内存测试制造/授权密钥、合成网络及虚拟时钟 |
| `run.mjs` | 只允许固定合成场景的 CLI |
| `protocol.test.mjs` | 协议、身份、分片、生命周期与日志反例 |

会话使用 P-256 临时 ECDH、HKDF-SHA256 和双向独立 AES-256-GCM 密钥，固定128位认证标签并严格检查 canonical base64url。每方向递增序号构造唯一 nonce，AAD/密钥派生绑定目标、申请、双方临时公钥、随机数、授权摘要、会话及方向；签名采用测试制造 Ed25519 身份。首个坏加密包终结当前通道；机器人同步失效当前会话并回滚本 attempt，不能继续尝试截短标签或继续应用迟到结果。客户端关闭通道不独立证明远端已回滚，真实机器人仍须以自身超时/断连处理确认。私钥不导出或落盘。配置授权的测试签发者与制造身份是两把不同的密钥，终端公钥绑定又是另一层，均不等于云端归属。

新会话清除旧 IP/挑战状态；commit 独立核对当前设备、申请、地址、期限和本次挑战。旧会话中签名真实的 IP proof 也不能在新通道提交。

这是可测试的通信参考构造，尚未经过生产密码协议审计；不能直接认定可上线。接入 Android/BlueZ 前应固定跨语言规范/测试向量、复用已审查的身份和授权机制，并独立审查具体加密实现。Node 进程内对象不保证所有口令/密钥副本被即时清零；本工具不处理真实凭据。

## 暂定 GATT 计划

以下仅为本地设计常量，未在机器狗上注册，不代表当前设备广播的 UUID：

| 角色 | 暂定 UUID | 属性 |
| --- | --- | --- |
| 服务 | `bc8d1000-7c0e-4a4e-a5d4-60f8cbdc0001` | DOSO 配网 |
| Info | `bc8d1001-7c0e-4a4e-a5d4-60f8cbdc0001` | read，版本/能力/身份线索；不授予归属 |
| Session | `bc8d1002-7c0e-4a4e-a5d4-60f8cbdc0001` | write + indicate，授权与会话协商 |
| Data | `bc8d1003-7c0e-4a4e-a5d4-60f8cbdc0001` | write + indicate，加密配置及状态 |

有效 ATT payload 为协商 MTU 减3；每帧另有7字节版本/序号/片数/总长头。总消息上限4096字节，MTU限制23至247，按实际 payload 分片；已覆盖23和185。重复、乱序、混合长度、超长及过期片段清空未完成消息。真实设备仍需验证 MTU、GATT 属性、indication 确认、丢包和断连恢复；当前工具不自动重发凭据，失败需要明确的新会话。

SSID 按 UTF-8 字节计1至32，拒绝 NUL 和不完整代理字符；不擅自 trim。此切片仅支持 WPA2-Personal 的8至63可打印 ASCII 口令或64位十六进制 PSK，不声称覆盖开放网络、企业 Wi-Fi、隐藏网络或 WPA3 的所有输入规则。

## 机器狗与 App 仍需补的真实代码

- 机器狗：Linux 驱动/固件使 HCI 可用，确认 LE peripheral/advertising；BlueZ GATT 服务；制造身份及配置授权验证；有取消/超时/回滚的系统网络适配器；状态通知及 IP 侧身份复核。配网服务与 Brainstem 电机控制循环分开，不因此使能或重启运动服务。
- App：现有 BLE 封装补业务 characteristic read/write/indication、MTU与断连处理；原生安全会话实现；临时凭据输入与安全清理；真实状态和失败原因展示。扫描/连接/服务发现不能替代这些能力。
- 授权：把模拟配置 grant 替换为已设计并审查的真实授权入口，校验当前所有者/成员权限和撤销代次；不把 Wi-Fi 配网当作设备认领。真正的持久防重放、恢复出厂/重启与丢失终端生命周期仍需实现。
- 时钟：分片及本地超时应使用单调时钟，授权有效期使用经核验的时间来源；本工具只注入可控虚拟时钟，未证明真实设备时钟/延迟。

USB 蓝牙模块必须与机器狗实际内核/架构/固件兼容，并在 BlueZ 下支持所需 LE 外设能力。当前公开实机记录无可用 HCI；本工具不能证明任意 USB 模块插上就能完成配网，也没有部署真实 GATT 或配网守护进程。
