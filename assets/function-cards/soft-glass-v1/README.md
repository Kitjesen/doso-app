## 使用

- preview.html 是静态摆放预览，不连接机器人，不模拟在线状态，不代表功能已接入。
- 先在白色或近 #F5F5F5 卡片上使用；透明材质和柔和阴影需要在最终底色上验收。
- 原图中没有功能文字，名称、真实状态、禁用态和操作结果由 App 组件显示。主视觉可能保留原有 DOSO 产品标识。
- 不将整个预览当作截图嵌入 App；应分别使用五张素材，再由原生布局绘制文字和点击区域。
- 保留这些原图作为制作源文件；正式打包前按目标卡片像素尺寸另行输出压缩版本并测量加载内存。本轮没有修改 App 的素材导入或 G20 安装包。
