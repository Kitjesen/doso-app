# Legacy registry-only assets

这些图片仍保留在 `assets/figma`，用于历史设计回溯和旧截图核对。它们已经从 `src/assets.ts` 的运行时图片注册表移除，因为当前生产代码没有引用它们。

历史注册项包括以下资源组：

- 首页快捷卡、指标卡和旧导航图
- 机型选择的旧网格和控件合成图
- 任务页摘要、日期、标题、卡片和旧导航合成图
- 分析页图表、性能、月份和旧导航合成图
- 路线页旧地图合成图

当前运行时注册表只保留确实被生产页面或设备测试使用的机器人图像。`src/design-qa` 使用的预览素材仍属于 QA 预览范围，不进入生产页面。
